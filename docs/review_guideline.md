# 검수 기준 (Review Guideline)

LLM 1차 생성 데이터를 조문·판례 원문(국가법령정보센터)과 1:1 대조하여 검수한다.
검수는 **자동 검수(규칙 기반)** 와 **수동 검수(원문 대조)** 2단계로 진행한다.

## 1. 핵심 검수 기준

| 코드 | 기준 | 확인 내용 | 자동 | 수동 |
|---|---|---|:-:|:-:|
| **C1** | **근거 조문 일치** | 인용 조문·항·호가 원천에 존재하고, 지문의 쟁점에 실제로 적용되는 조문인가 | 존재 여부 | 적용 적합성 |
| **C2** | **판례 최신성** | 근거 판례가 현재 유효한가(변경되지 않았는가). 판례 변경 문항은 변경 선언 문구가 원문에 있는가 | 변경 선언 문구 검출 | 후속 판례·법 개정 확인 |
| **C3** | **결론–근거 정합성** | [대전제]→[소전제]→[결론]이 논리적으로 이어지고, 정답(O/X)이 근거와 일치하는가 | 형식(O/X 존재) | 논리·정답 |

## 2. 보조 기준

| 코드 | 기준 | 확인 내용 |
|---|---|---|
| A1 | 환각 금지 | 텍스트에 등장하는 모든 사건번호·조문번호가 원천 데이터에 존재 (자동) |
| A2 | 판결요지 충실성 | `holding`이 판결요지의 범위를 넘는 일반론·과장을 포함하지 않음 (수동) |
| A3 | 단일 함정 | OX 오답 지문은 기간·주체·요건·효과 중 하나만 변형 (수동) |
| A4 | 현행법 기준 | 개정 전 기간·명칭(예: 6개월, 특허청장)을 현행 규정처럼 쓰지 않음 (수동) |
| A5 | 평가셋 분리 | 평가셋 근거 판례·조문이 학습셋(SFT·DPO)과 겹치지 않음 (자동) |
| A6 | DPO 지름길 차단 | rejected에 "종전/변경 전" 같은 표지가 없고, chosen과 형식·길이가 비슷함 (수동) |

## 3. 자동 검수 (`src/build_dataset.py`)

1. **대전제 원문 자동 삽입**: SFT의 조문 인용은 LLM 출력이 아니라 API 원문에서 항·호·목 단위로 삽입
2. **사건번호 검증**: 모든 텍스트에서 사건번호를 추출해 `precedents.jsonl` 또는 변경 목록(`overruled_cases`)과 대조
3. **조문번호 검증**: 텍스트 속 `○○법 제N조`가 `statutes.jsonl`에 존재하는지 확인
4. **판례 변경 검증**: `precedent_conflict`의 근거 판례가 원문 변경 선언 문구로 확정된 15건에 속하는지 확인
5. **DPO 검증**: chosen에 근거 판례가 있고, rejected에 실제로 변경된 종전 판례 사건번호가 있는지 확인
6. **누수 검사**: 판례·조문 단위 중복과 지문 중복을 검사
7. 오류가 1건이라도 있으면 빌드를 실패시키고 `data/build_report.json`에 기록

> 검증 테스트: 존재하지 않는 사건번호(`2019후99999`)와 조문(`특허법 제999조`)을 일부러 넣으면 빌드가 실패하는 것을 확인했다.

## 4. 수동 검수 절차

1. `data/review/review_sheet.csv`를 연다(문항별로 근거 원문 URL이 함께 들어 있음).
2. 각 문항의 근거 링크(국가법령정보센터)를 열어 C1~C3, A2~A4를 확인한다.
3. 판정을 기록한다.
   - `PASS`: 수정 없이 사용
   - `FIX`: 표현·근거를 고쳐 사용(수정 내용을 `note`에 기록)
   - `DROP`: 폐기(사유 코드를 `note`에 기록)
4. FIX·DROP은 `data/generated/*_raw.jsonl`에 반영하고 `python src/build_dataset.py`를 다시 실행한다.

### 검수 범위
- `precedent_conflict`, `rule_precedent_exception`: **전수 검수**(SFT·DPO·평가셋 모두)
- `standard`: 조문 문항은 자동 원문 삽입으로 C1 위험이 낮으므로, 판례 문항은 전수, 조문 문항은 표본 검수

## 5. 오류 유형 코드 (DROP/FIX 사유)

| 코드 | 유형 | 예 |
|---|---|---|
| E-CITE | 근거 조문 부적합 | 쟁점과 무관한 항을 인용 |
| E-STALE | 판례 최신성 위반 | 변경된 판례를 현재 법리처럼 서술 |
| E-LOGIC | 결론–근거 불일치 | 소전제와 결론이 반대 |
| E-OVER | 판결요지 범위 초과 | 판결에 없는 요건 추가 |
| E-AMEND | 개정 전 규정 사용 | 공지예외 기간을 6개월로 서술 |
| E-AMBIG | 정답 모호 | O/X가 해석에 따라 갈림 |

| 원천 수집 | 2021두59908의 변경 대상 판례가 앞 문장만 보고 추출되어 누락 | 마지막 변경 선언 문장 기준으로 재추출 → 8건 확보 |
