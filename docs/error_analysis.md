## 2. 오류 패턴

### ① 지문 복제형 대전제 — 25/60건
지문 문장과 [대전제] 문장의 문자 일치율이 70% 이상인 응답. 25건 중 23건이 O로 답했고 정답은 14건이다.
지문을 근거로 위장해 지문을 정당화하는 **순환 논증**이며, O 쏠림(SFT 예측 O 49 : X 10)의 주원인이다.

| id | 지문 (정답) | SFT 대전제 | SFT 결론 |
|---|---|---|---|
| eval-std-022 | 궁박·경솔·무경험으로 현저하게 공정을 잃은 법률행위는 **취소**할 수 있다. (X, 민법 제104조: 무효) | 민법 제109조 제2항: "… 법률행위는 취소할 수 있다." (조·항은 실재하나 내용은 가공 — 실제 제109조 제2항은 착오 취소의 제3자 효력 규정) | O |
| eval-exc-005 | 소유자가 개인적 사용 목적으로 리폼한 가방에 상표가 있으면 침해가 성립한다. (X, 2024다311181) | 대법원 2025. 4. 29. 선고 2024다276830 전원합의체 판결: (지문과 동일 문장) (가공) | O |

### ② 가공 판례 — 18/18건
사건번호·선고일·전원합의체 표기까지 형식은 완벽하지만 존재하지 않는 판례다. 평가셋 판례는 학습셋에 없으므로(누수 차단), 모델은 판례 **내용**을 알 수 없고 **형식**만 재현한다.
정답 근거 판례(34문항)를 인용한 응답은 0건이다.

### ③ 조문 번호 고착 — 37/56건
인용 조문 56건 중 37건이 "특허법/상표법 제103조 제2항"(실제 특허법 제103조·상표법 제103조는 모두 항이 없는 단일 조문)이다. 쟁점과 무관하게 같은 번호가 반복된다.

### ④ 반복 생성(degeneration) — 1건
eval-conf-007에서 언어 이름을 끝없이 나열하다 토큰 한도에 도달해 O/X를 출력하지 못했다(파싱 실패 1건).

## 3. Base 모델 관찰
- 60문항 중 58문항을 O로 답했다. 삼단논법 태그를 쓰더라도 "[소전제] 이 지문은 판단하기 어렵다 … [결론] - O" 같은 무근거 응답이 대부분이다.
- 조문·판례 인용 0건. 환각은 없지만 근거도 없다.

## 4. 평가 과정의 오류와 수정
- 최초 집계에서 Base 정답률이 26.7%로 나왔다. 원인은 파서가 `[결론] - O`(대시 포함) 형식을 인식하지 못해 29문항을 파싱 실패로 처리한 것이다.
- 파서를 수정하고 **저장된 출력 원문을 재채점**했다(모델 재실행 없음). 수정 후 Base 51.7%.
- 수정 전 수치(26.7% → 58.3%, +31.6%p)는 SFT 효과를 부풀리므로 사용하지 않는다.

## 5. 시사점
1. **SFT로 근거 형식을 가르치면 환각이 '그럴듯해진다'.** 형식 준수율만 보면 성공이지만, 근거의 실재성은 오히려 나빠졌다(Base 인용 0건 → SFT 가공 인용 다수).
2. 데이터 구축 단계에서 쓴 원칙("대전제는 원문에서")을 **추론 단계에도 적용**해야 한다 → 조문·판결요지 검색 증강(RAG).
3. 이번 SFT 출력의 가공 인용 응답은 그대로 **DPO rejected 후보**가 된다(실재 인용 응답을 chosen으로).
4. 법률 모델 평가는 정답률과 함께 **인용 실재성·근거 일치율**을 1차 지표로 봐야 한다.
