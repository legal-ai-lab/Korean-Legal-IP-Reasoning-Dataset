## 3. Base 모델 관찰
- 60문항 중 58문항을 O로 답했다. 삼단논법 태그를 쓰더라도 "[소전제] 이 지문은 판단하기 어렵다 … [결론] - O" 같은 무근거 응답이 대부분이다.
- 조문·판례 인용 0건. 환각은 없지만 근거도 없다.

## 4. 평가 과정의 오류와 수정
- 최초 집계에서 Base 정답률이 26.7%로 나왔다. 원인은 파서가 `[결론] - O`(대시 포함) 형식을 인식하지 못해 29문항을 파싱 실패로 처리한 것이다.
- 파서를 수정하고 **저장된 출력 원문을 재채점**했다(모델 재실행 없음). 수정 후 Base 51.7%.
- 수정 전 수치(26.7% → 58.3%, +31.6%p)는 SFT 효과를 부풀리므로 사용하지 않는다.

## 5. 시사점
1. **SFT로 인용 형식을 학습시키면 가공 인용이 늘어난다.** 형식 준수율은 높아졌지만 근거의 실재성은 나빠졌다(Base 인용 0건 → SFT 가공 인용 다수).
2. 데이터 구축 단계에서 쓴 원칙("대전제는 원문에서")을 **추론 단계에도 적용**해야 한다 → 조문·판결요지 검색 증강(RAG).
3. 이번 SFT 출력의 가공 인용 응답은 그대로 **DPO rejected 후보**가 된다(실재 인용 응답을 chosen으로).
4. 법률 모델 평가는 정답률과 함께 **인용 실재성·근거 일치율**을 1차 지표로 봐야 한다.

## 6. DPO 모델 (SFT 위 LoRA DPO, 44쌍)

| 관찰 | 수치 |
|---|---|
| 학습 쌍 선호 정확도 | 100% (loss 0.693 → 0.001, 보상 마진 8.24) |
| 평가셋 정답률 | SFT 58.3% → **45.0%** (판례 변경 40% → 20%) |
| '전원합의체' 언급 응답 | SFT 6/60 → **45/60** |
| 가공 사건번호 | SFT 19/19 → **45/45** |
| 형식 준수율 / 파싱 실패 | 98.3% → 88.3% / 1 → 7 |

**해석**: 판례 변경 34쌍의 chosen은 모두 "전원합의체 판결 + 종전 판례 변경" 형식이고, rejected는 그 형식이 없다. 44쌍으로 3 epoch를 학습하자 모델은 *판례 내용*이 아니라 *형식적 단서*로 chosen을 구별하도록 학습되었다(학습 쌍 100%, 평가셋 하락). 데이터 설계 단계에서 rejected의 "(종전 판례)" 문구는 제거했지만, chosen 쪽 문구("전원합의체", "변경되었다")가 같은 문제를 만들었다.

**개선 방향**: (1) chosen·rejected 모두 같은 인용 형식을 갖도록 쌍을 재설계해 차이를 판례 내용에만 두기, (2) β 상향·epoch 축소·조기 종료, (3) 학습에 쓰지 않은 검증용 선호 쌍으로 과적합 모니터링, (4) 추론 시 원문 검색 증강.
